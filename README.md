# SonoPromptAttack

Project page for [*When Minor Edits Matter: LLM-Driven Prompt Attack for Medical VLM Robustness in Ultrasound*](https://arxiv.org/abs/2603.21047).

- Live site: [sonopromptattack.github.io](https://sonopromptattack.github.io/)
- Code: [yasamin-med/SonoPromptAttack](https://github.com/yasamin-med/SonoPromptAttack)
- Interactive explorer: [`/explorer/`](https://sonopromptattack.github.io/explorer/) — 200 recorded successful attacks with images, prompts, edits, and prediction flips

## Local preview

```bash
python3 -m http.server 8765
```

Then open `http://127.0.0.1:8765/` and `http://127.0.0.1:8765/explorer/`.
